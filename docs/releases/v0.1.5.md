# LocalDictate v0.1.5 — insertion confirmation

## Change

- The keyboard or the target app emit focus/window events right after insertion; they made the insertion wrongly reported as not confirmed (seen in Google Keep). Confirmation now relies on reading the focused field: same app and field, exact expected text, expected cursor. Confirmed insertion: local transcript cleared and bubble ready for the next dictation.
- Different field, text or cursor: still "not confirmed", text kept. The text is never resent automatically.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models.
