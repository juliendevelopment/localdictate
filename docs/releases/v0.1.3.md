# LocalDictate v0.1.3 — chaining dictations after a successful insertion

## Changes

- After insertion, the confirmation reads the field several times (about 1.5 s) without ever resending the text. A cursor difference alone no longer blocks when the expected text is exactly there. Text events from the target app during the send are no longer taken as a target change; a focus or window change stays "not confirmed".
- Observed insertion: the local transcript is cleared and the bubble goes back to « ● Dicter », without disarming or copying. Not confirmed, refused or no field: the text is kept as before, with the non-sensitive reason shown.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models. Multi-app and endurance tests still to do on the phone.
