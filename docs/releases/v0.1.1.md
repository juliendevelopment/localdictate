# LocalDictate v0.1.1 — diagnostic de la cible d’insertion

## Changement

- Quand l’insertion automatique n’a pas de cible (par exemple dans Google Keep), le message indique maintenant la raison précise du refus : champ au focus absent, champ non éligible, éditeur direct indisponible ou différent du champ. Aucun contenu de texte n’est affiché.
- Aucune règle de sécurité n’est assouplie : la correction de la cause se fera à partir de ce diagnostic.

## Installation

Même procédure que la v0.1.0 (`docs/releases/v0.1.0.md`) ; l’APK est signé avec la même clé et s’installe par-dessus. Les modèles déjà préparés sont conservés.
