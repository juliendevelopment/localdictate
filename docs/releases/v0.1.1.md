# LocalDictate v0.1.1 — insertion target diagnosis

## Change

- When automatic insertion has no target (for example in Google Keep), the message now gives the exact reason: no focused field, ineligible field, direct editor unavailable or different from the field. No text content is shown.
- No safety rule is relaxed: the cause will be fixed from this diagnosis.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models. The APK is signed with the same key.
