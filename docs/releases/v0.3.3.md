# LocalDictate v0.3.3 — long speakerphone passages no longer stop the transcription

## Fix

- Transcription of a recording could fail at the same point on every attempt (« Échec du traitement ou stockage »). Cause: on continuous speech, such as a call on speakerphone with no pause, the speech detector can return a passage longer than its 20 s limit (23 s on the reported call), which the transcription refused. Such passages are now split at their quietest moment, without losing or repeating anything. Dictation benefits from the same protection.
- If a transcription still fails, the message now says where (in seconds) and why, and each « Retranscrire » shows only its own result instead of repeating the previous messages.

Checked by host tests and by replaying the reported recording's speech detection on a computer; to be confirmed on the phone with « Retranscrire » on that recording.

## Installation

Installs over the previous version and keeps the models, recordings, history and statistics. Includes the v0.3.2 changes (no in-app summary, Markdown export of the plain transcript, delete button per meeting).
