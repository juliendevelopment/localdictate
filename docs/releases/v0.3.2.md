# LocalDictate v0.3.2 — transcript only, for your LLM

## Changes (« Réunion » tab)

- **The in-app summary is removed.** It only picked original sentences and was confusing. Copy the transcript (« Copier la transcription (texte brut) ») or export it as Markdown, then ask the LLM of your choice for a summary.
- **Markdown export = the plain transcript**: a short header (date, approximate duration, a note that the transcript is automatic), then the text in paragraphs, without timestamps, anchors or summary.
- **« Supprimer » on each saved meeting** in the list, with a confirmation (audio and transcripts are deleted from the phone).
- **The selected mode is highlighted**: « Dictée » or « Réunion » is the filled button.

Recordings made with v0.3.0–v0.3.1 still open, copy, export and can be re-transcribed; their old summary is no longer shown and is deleted with the meeting.

Checked by host tests only (JVM/Robolectric, lint, builds).

## Installation

Installs over the previous version and keeps the models, recordings, history and statistics.
