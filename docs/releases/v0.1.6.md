# LocalDictate v0.1.6 — reliable insertion, copy fallback and history

## Changes

- Cause of the failure seen on longer dictations: the generic `TYPE_WINDOWS_CHANGED` event (keyboard or bubble window) cancelled the target. It no longer does: field, window, view id, text and selection are still re-checked before and after insertion. A real window or focus change still cancels the target.
- If insertion is not confirmed (changed target, composition, incompatible editor, confirmation impossible), the text is copied automatically to the clipboard (flagged sensitive), replacing the previous clip. The text is still never resent automatically into the field.
- History of the last 5 dictated texts, stored privately on the phone, with Copy per entry and « Effacer l’historique ».

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models.
