# LocalDictate v0.3.9 — your own words, model preparation fixed

## Your own words (« Mes mots »)

- A new « Mes mots » box under the dictation tab. Write one word or name per line (for example `Parakeet`): the recognizer favours these words when what you say is close to them. To fix an error that always comes back the same way, write `entendu => voulu` (for example `para kit => Parakeet`): the recognized text is corrected, whole words only, upper and lower case ignored.
- Saved on the phone only, applied from the next dictation and the next meeting transcription, without restarting the bubble.
- To support favoured words, recognition now compares several hypotheses instead of keeping only the best one at each step. On the computer, with the same model, the text of the test sentences is unchanged and recognition takes about 15 % longer. How much the favoured words help on your own words is still to be seen on the phone.

## Model preparation

- « Préparer » failed on a phone without the model since 7 November 2026: the sherpa-onnx project replaced the model archive with a different one, which the app refused, as designed. The app now downloads the same four verified files one by one from a fixed revision that cannot change (about 670 MB), like the Linux version. Phones that already have the model keep it and download nothing.

Checked by host tests only; to be confirmed on the phone (see the next phone session in the status page).

## Installation

Installs over the previous version and keeps the models, recordings, history and statistics.
