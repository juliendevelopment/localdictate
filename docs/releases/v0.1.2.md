# LocalDictate v0.1.2 — insertion in Google Keep

## Change

- The Android field and editor are now considered the same when their input class and variation match, even if the editor adds flags (seen in Google Keep: 704513 vs 2801665). Strict equality used to refuse the target.
- Other checks still apply: package, view id, unchanged text and selection, no composition, no password. Changed or incompatible target: text kept and manual copy.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models. Insertion in other apps remains to be checked on the phone.
