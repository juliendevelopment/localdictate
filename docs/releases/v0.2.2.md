# LocalDictate v0.2.2 — screen stays on while dictating

## Change

- The screen no longer turns off during a long dictation: while the bubble shows the ✕ | level | ✓ pill and while the last segments are processed, the bubble window asks Android to keep the screen on. As soon as the bubble is back at rest, the normal screen timeout applies again.

## Installation

Installs over the previous version and keeps the models. See the v0.2.1 notes for a first installation.
