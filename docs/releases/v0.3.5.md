# LocalDictate v0.3.5 — dictation into empty chat fields

## Fix

- In Discord, and in Paseo when the message field was empty, the text was not inserted and was copied instead (« Pas de champ compatible au démarrage … sélection=-1--1/0 »). Android does not report the cursor of an empty text field to accessibility, and LocalDictate required one. An empty field has only one possible cursor position, the start, so the text is now inserted there. A field that already holds text but reports no cursor is still refused (copy fallback), so nothing is ever placed blindly.

Checked by host tests only; to be confirmed on the phone in Discord and Paseo with an empty field, then with existing text, and in Keep.

## Installation

Installs over the previous version and keeps the models, recordings, history and statistics.
