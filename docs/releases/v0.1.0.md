# LocalDictate v0.1.0 — first dictation build to test

## Features

- Local French and English speech recognition: Parakeet TDT 0.6B v3 int8 and Silero VAD, no translation or rewording.
- Explicit model preparation with progress, resume and size/SHA-256 checks. No weights in the APK.
- Draggable bubble: armed from the visible screen, microphone closed at rest, start/stop by tapping. Pauses do not end the dictation; 15-minute capture limit.
- Last segments processed after stop; transcript kept in private storage for recovery.
- Direct insertion at the cursor through the accessibility editing API on compatible Android 13+, without changing keyboard or using the clipboard automatically. Changed target, active composition, protected/incompatible field or unavailable connection: transcript kept and explicit manual copy. Sending a command is not presented as proof of an observed insertion.
- Notifications, explicit stop/disarm, and no listening when the app starts.

## Installation and first try

1. Download `LocalDictate-v0.1.0.apk` from this release and allow installation from the browser if Android asks.
2. Open LocalDictate and prepare the models with an Internet connection: about 488 MB to download, at least 1.5 GB free. Each app has its own private storage, so models are not shared with other apps.
3. Grant microphone, notifications, display over other apps and the LocalDictate accessibility service. If Android blocks the latter for a sideloaded APK, open Settings → Apps → LocalDictate → ⋮ menu → Allow restricted settings, then go back to Accessibility. Labels vary between Android versions.
4. Arm the bubble, go to a notes app, place the cursor in a field and tap **Dicter**. Say a few sentences in French, stop and check the text. Repeat in English.
5. Start with a non-sensitive field; check that the text before/after the cursor and the clipboard are kept. The fallback copy is deliberate and replaces the clipboard; the sensitive flag hides previews but does not prevent access by the keyboard or the receiving app.
6. For a new dictation after a kept text, copy it if needed, disarm, then tap Clear before arming again, so a transcript to recover is never lost.

## Limits of this first delivery

The **2-hour meeting + local summary** mode is a separate phase in development; its button does not pretend to record or summarize a meeting in this version.

JVM/activity tests, lint and APK checks do not replace phone tests. JNI loading, FR/EN quality, insertion in native/web apps, Gboard behavior, keeping the service alive, airplane mode/return of network, real 15-minute duration, memory, latency, battery and heat remain to be tested on the phone. A process interruption loses audio still in RAM; text already synced remains recoverable. Insertion is not promised to work everywhere.

The release signature is dedicated to LocalDictate and kept for updates. Do not uninstall to update: models and local data would be lost.
