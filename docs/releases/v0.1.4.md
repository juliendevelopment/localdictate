# LocalDictate v0.1.4 — precise reasons for insertion refusals

## Changes

- Accessibility events from LocalDictate itself (bubble, app) no longer invalidate the insertion target.
- Each insertion refusal now gives its non-sensitive reason: target invalidated (with event type and package), text or cursor changed (lengths and positions only), stale editor or editor state. No text content is shown.
- Copy no longer replaces the insertion result: it is kept after « Dernier résultat : ».
- Safety rules unchanged: changed target, composition or protected field keep the text with a manual copy.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models.
