# LocalDictate v0.2.4 — insertion into empty chat fields

## Fix

- Automatic insertion into an empty field that shows a placeholder (« Message », « Envoyer un message… »), as in Discord and messaging apps. Android reports that placeholder as the field's text, so the field never matched the keyboard's empty editor and the dictation was copied instead. A field showing its placeholder now counts as empty. All other protections are unchanged: nothing is replaced, password fields are excluded, a refused insertion is still copied and kept in the history.

Checked by host tests only; insertion in Discord and messaging apps is still to be confirmed on a phone.

## Installation

Installs over the previous version and keeps the models. See the v0.2.1 notes for a first installation.
