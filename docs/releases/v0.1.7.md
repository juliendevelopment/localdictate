# LocalDictate v0.1.7 — insertion no longer cancelled by other apps

## Change

- Only focus or window events from the target app cancel the insertion target. Events from the system UI (seen: `com.android.systemui`), the keyboard and the bubble no longer do. Switching apps is still refused: the focused field, its package, window, text and selection are re-checked before and after insertion.
- The automatic copy fallback and the history of 5 texts from v0.1.6 are unchanged.

## Installation

Same procedure as v0.1.0; installs over the previous version and keeps the models.
